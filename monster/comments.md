A REST API for task management (To-Do List), implemented in the Django REST Framework using MongoDB.
A project for a fully-featured computer server architecture with caching, task queues, and containerization.
Features:

1. CRUD operations for tasks (GET, POST, PATCH, PUT, DELETE)

2. Data storage in MongoDB (via MongoEngine)

3. Message caching using Redis (WSl)

4. Asynchronous background tasks via Celery

5. Logging and metrics collection (django-prometheus)

6. Partial update support (PATCH)

7. Containerization with Docker / Docker Compose

Tech Stack: Python 3.13.1, Django + Django REST Framework, MongoDB, Redis, Celery, Unicorn, Docker
